# NotiFlash - Angular

Implementación en Angular de NotiFlash (Entrega 3 - Front End).

## Requisitos previos

- Node.js (v18 o superior)
- npm

## Instalación y ejecución

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor local de desarrollo:
   ```bash
   npm start
   ```

3. Abrir en el navegador:
   http://localhost:4200

## Compilación para producción

```bash
npm run build
```
